# Pack Pulse Next.js – pour /pulse:nouveau

Le pack Pulse Next.js est installé : à l'étape « Les outils », sa pile ouvre la voie directe de `/pulse:tech` quand le projet a des écrans, des comptes ou des données partagées. Les déductions de l'étape 3 se traduisent en recettes : comptes → `connexion` ; listes, fiches, tableaux → `liste` ; e-mails envoyés par l'application (confirmation, notification) → `envoi-email` ; e-mails du compte (adresse confirmée, mot de passe oublié) → `email` (avec `envoi-email`) ; code de connexion reçu par e-mail → `double-authentification` (avec `email`) ; fichiers → `fichiers` ; paiement → `paiement` ; plusieurs langues → `langues` ; formulaires publics → `formulaire-public` (avec `limite`) ; être trouvé sur Google → `seo`. Les noter dans la ligne « Il faudra » de l'écran de validation.
