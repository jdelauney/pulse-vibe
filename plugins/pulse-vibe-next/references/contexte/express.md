# Pack Pulse Next.js – pour /pulse:express

Le pack Pulse Next.js est installé : à l'étape « Les outils », sa pile est l'option à présenter en premier quand le projet a des écrans, des comptes ou des données partagées. Les déductions de l'étape 3 se traduisent en recettes : comptes → `connexion` ; listes, fiches, tableaux → `liste` ; e-mails → `email` ; fichiers → `fichiers` ; paiement → `paiement` ; plusieurs langues → `langues` ; formulaires publics → `limite`. Les noter dans la ligne « Il faudra » de l'écran de validation.
