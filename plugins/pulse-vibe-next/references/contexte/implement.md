# Pack Pulse Next.js – pour réaliser et corriger

- Appliquer la fiche ci-dessous à chaque fichier. En cas de doute sur une API de Next.js, lire `node_modules/next/dist/docs/` (exacte pour la version installée) avant d'écrire.
- Nouveau fichier ou dossier, entité, use-case, repository, action ou container : appliquer `pulse-aidd pile reference architecture.md` ; pour ces modèles, suivre `pulse-aidd pile reference modeles-code.md`.
- Une tâche qui cite une recette (« Recette : connexion ») : afficher sa vue d'ensemble avec `pulse-aidd pile recette <nom>` (fichiers, liste des étapes, sécurité, pièges), puis chaque étape utile à la tâche au moment de l'écrire, avec `pulse-aidd pile recette <nom> etape <id>`, et le code de ses tests avec `pulse-aidd pile recette <nom> tests`. Suivre ses étapes dans l'organisation de la fiche.
- Une tâche « Entité : <sujet> » : lire `pulse-aidd pile reference entite.md`, écrire la description JSON d'après les « Informations manipulées » de la spec, contrôler la liste des fichiers avec `pulse-aidd pile entite <description> --essai`, puis lancer `pulse-aidd pile entite <description> --us <US-XXX>` et faire les gestes qu'il affiche. Ensuite, seulement l'écart avec la spec : règles métier (méthode de l'entité, use-case et ses tests), libellés, titres des tests renommés d'après les scénarios.
- Nouvelle bibliothèque : seulement celles qu'une recette ou la fiche prévoit, à leur dernière version (`npm view <paquet> version`, puis `npm install <paquet>`), avec l'accord de la personne.
- Recette réalisée qui demande un outil sur le poste (`envoi-email`, `paiement`) : ajouter sa ligne à « Tester en local » de `README.md` (`pulse-aidd pile reference readme.md`).
- Composant d'interface écrit ou modifié : lancer `pulse-aidd pile reference react.md --checklists` et l'appliquer (la référence entière, `pulse-aidd pile reference react.md`, quand une ligne ne suffit pas à décider) ; `npx shadcn@latest add <composant>` s'il manque, puis rôles du thème uniquement. Animation, survol ou défilement à réaliser : `pulse-aidd pile reference mouvement.md`.
- Une erreur de Next.js liée à Cache Components (route bloquante, donnée non mise en cache lue hors de `Suspense`, donnée de requête dans `"use cache"`) se corrige comme le message le propose : `[stream]` → envelopper dans `Suspense` ; `[cache]` → `"use cache"` pour une donnée commune à tous ; jamais `export const dynamic`.
- Avant de rendre la main : `npm run check`, `npm run typecheck`, `npm test` (et `npm run format` pour la mise en forme).
