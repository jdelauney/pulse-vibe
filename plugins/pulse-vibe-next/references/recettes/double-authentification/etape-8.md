### 8. Essayer en local

Mailpit lancé, `npm run dev`. Connectez-vous, ouvrez « Mon compte », saisissez votre mot de passe sous « Double authentification » et activez-la. Déconnectez-vous, reconnectez-vous : la page « Code de connexion » s'affiche ; le code arrive dans Mailpit (http://localhost:8025), avec l'objet « Votre code de connexion ». Saisissez-le : « Mon compte » s'affiche. Essayez aussi un code faux, puis « Renvoyer le code ».
