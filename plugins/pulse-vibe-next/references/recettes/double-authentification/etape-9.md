### 9. Mettre en ligne

Appliquez la migration de l'étape 1 à la base de production (`npm run db:migrate`, ou `npm run mise-en-ligne`), puis redéployez. Aucune variable nouvelle : le code part par le serveur d'e-mail de la recette `email`. Sur le site en ligne, activez la double authentification sur votre compte, reconnectez-vous : le code arrive dans votre boîte.
