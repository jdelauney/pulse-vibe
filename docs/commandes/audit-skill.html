/pulse:audit-skill

Auditer une skill, un dossier de skills ou un plugin selon les règles d'optimisation, avec un rapport et sans rien modifier.

    Description

    Une skill est une compétence que vous ajoutez à Claude Code : un dossier avec un fichier SKILL.md qui lui dit comment faire un travail. /pulse:audit-skill relit une skill, toutes celles d'un dossier, ou celles d'un plugin, et vous dit ce qui peut être mieux écrit.

    Pulse s'appuie sur 14 règles, tirées du travail qui a allégé Pulse lui-même. Un programme fait d'abord les mesures (tailles, autorisations, longueur de la description, la phrase qui dit à Claude quand utiliser la skill). Puis un assistant juge le reste : doublons, utilité, questions gardées, mots adaptés à qui lira.

    Le résultat est un rapport. Vos skills ne sont pas modifiées.

    Pourquoi l'utiliser

    • Moins de texte chargé à chaque usage. Le rapport chiffre ce que chaque correction ferait gagner.
    • Des autorisations sans surprise. Une skill qui autoriserait d'avance un geste risqué (supprimer, envoyer) est signalée en premier.
    • Des skills qui servent. Avec votre accord, Pulse compte combien de fois chaque skill a été lancée ces 90 derniers jours.

    Quand l'utiliser

    1. 1 Démarrer
    2. 2 Décrire
    3. 3 Préparer
    4. 4 Construire
    5. 5 Mettre en ligne
    6. 6 Être trouvé
    7. 7 À tout moment
    • Vous avez écrit ou récupéré des skills et vous voulez savoir si elles sont bien faites.
    • Claude Code vous semble lent ou distrait quand vos skills sont chargées.
    • Avant de partager un plugin avec d'autres personnes.

    Comment la lancer

    /pulse:audit-skill [chemin d'une skill, d'un dossier de skills ou d'un plugin]

    Entre crochets [ ] : facultatif. Entre chevrons < > : à remplacer par votre valeur. La barre | sépare les choix possibles. Par défaut : les skills et agents du projet, .claude/.

    • Rien : les skills et les assistants de votre projet, dans .claude/. Pulse vous propose d'ajouter vos skills personnelles, avec leur propre rapport. Un projet sans skill vous est signalé, sans rapport.
    • Le chemin d'une skill : cette skill seule.
    • Le chemin d'un dossier ou d'un plugin : toutes ses skills et ses assistants.
    /pulse:audit-skill .claude/skills/rediger-devis

    Ce qu'elle produit

    FichierÀ quoi il sert
    docs/audits-skills/<nom>-<date>.mdLe rapport, un par ensemble audité (votre projet, vos skills personnelles, un plugin) : les mesures, un avis par règle, les points à corriger rangés du plus grave au plus léger, et le gain estimé.

    Risques et précautions

    • Vos skills restent telles quelles. Seul le rapport est écrit.
    • L'historique de vos conversations est lu seulement si vous le demandez, sur votre ordinateur. Rien n'est envoyé ailleurs.
    • Une skill jamais lancée est signalée, jamais supprimée.

    Problèmes et solutions

    Pulse dit que le chemin n'existe pas

    Vérifiez le chemin du dossier de la skill, puis relancez la commande avec le bon chemin.

    Pulse dit que ce n'est pas une skill Claude Code

    La commande lit les skills au format de Claude Code : un dossier avec un fichier SKILL.md. Les règles d'autres outils ne sont pas lues.

    Exemples

    /pulse:audit-skill

    J'ai relu vos 3 skills. 1 point bloquant : la skill « publier » autorise d'avance l'envoi sur le dépôt en ligne. 2 points à corriger, 1 conseil. Si tout est corrigé, chaque lancement chargerait environ 4 000 caractères de moins. Le rapport est dans docs/audits-skills/skills-projet-2026-10-26.md.
