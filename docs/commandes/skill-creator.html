/pulse:skill-creator

Créer une skill Claude Code qui respecte les règles d'optimisation, après quelques questions sur son travail.

    Description

    Une skill est une compétence que vous ajoutez à Claude Code : un dossier avec un fichier SKILL.md qui lui dit comment faire un travail. /pulse:skill-creator l'écrit avec vous.

    Pulse vous pose quelques questions, une à la fois : le travail à faire, les phrases que vous direz, qui la lance, ce qu'elle touche, à qui elle parle, où la ranger. Il vous montre le plan de la skill, puis l'écrit une fois le plan validé.

    Un programme contrôle ensuite la skill selon les 14 règles tirées du travail qui a allégé Pulse. La skill obtenue fonctionne seule, sans Pulse.

    Pourquoi l'utiliser

    • Une skill juste du premier coup. Une description claire (la phrase qui dit à Claude quand utiliser la skill), un déroulé court, le détail chargé seulement quand il sert.
    • Des autorisations sans surprise. Les gestes risqués (envoyer, supprimer, mettre en ligne) restent soumis à votre accord.
    • Moins de texte chargé. La taille de la skill est mesurée avant de vous la rendre.

    Quand l'utiliser

    1. 1 Démarrer
    2. 2 Décrire
    3. 3 Préparer
    4. 4 Construire
    5. 5 Mettre en ligne
    6. 6 Être trouvé
    7. 7 À tout moment
    • Vous refaites souvent le même travail avec Claude Code et vous voulez lui apprendre une fois pour toutes.
    • Vous voulez partager une façon de faire avec les personnes de votre projet.

    Comment la lancer

    /pulse:skill-creator [ce que la skill doit faire]

    Entre crochets [ ] : facultatif. Entre chevrons < > : à remplacer par votre valeur. La barre | sépare les choix possibles. Vide : la première question vous le demande.

    • Rien : la première question vous demande ce que la skill doit faire.
    • Une phrase : le travail de la skill, en vos mots.
    /pulse:skill-creator rédiger un devis à partir d'une demande client

    Ce qu'elle produit

    FichierÀ quoi il sert
    .claude/skills/<nom>/SKILL.mdLa skill, rangée dans votre projet. Vous pouvez aussi la ranger pour vous seul, dans tous vos projets, ou dans un plugin.
    .claude/skills/<nom>/references/Au besoin, le détail d'une étape, lu seulement à cette étape.

    Risques et précautions

    • Une skill existante reste telle quelle. Si le nom est déjà pris, Pulse vous en propose un autre.
    • Hors de votre projet (vos skills personnelles, un plugin), Claude Code vous demande l'accord pour chaque fichier.

    Problèmes et solutions

    La nouvelle skill n'apparaît pas quand je tape son nom

    Fermez puis relancez Claude Code : il lit les skills au démarrage.

    Exemples

    /pulse:skill-creator rédiger un devis à partir d'une demande client

    Quelles phrases direz-vous pour vous en servir ? Par exemple « fais-moi le devis de ce message ».

    « Prépare le devis » ou « devis pour ce client ».

    Voici le plan : la skill rediger-devis, rangée dans ce projet, lancée par vous seul, en 3 étapes. Je l'écris ? … C'est fait : 0 point bloquant, 2 400 caractères chargés à chaque lancement. Essayez-la en tapant /rediger-devis avec une vraie demande.
