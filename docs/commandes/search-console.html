/pulse:search-console

Relier le site à Google Search Console (et Bing), puis lire ce que Google voit vraiment, en lecture seule — chiffres, requêtes à potentiel, pages oubliées, indexation — et suivre l'évolution tous les 28 jours.

    Description

    Search Console, c'est le tableau de bord que Google vous tend : ce qu'il a trouvé sur votre site, et ce que les gens ont tapé pour vous trouver. Cette commande vous y accompagne en trois temps.

    Relier, une seule fois : vous prouvez à Google que le site est à vous, vous lui donnez le plan du site, puis vous l'importez dans Bing. Lire : Pulse transforme les chiffres de Google en un rapport court, avec trois actions prioritaires. Suivre, tous les 28 jours : Pulse compare avec la période d'avant et relie les écarts aux changements faits sur le site.

    Tout se fait en lecture seule, avec votre propre compte Google. Pulse ne modifie rien chez Google : c'est vous qui cliquez dans l'interface.

    QuandCe qui se passe
    Jour 0Site relié, plan du site déclaré, import dans Bing.
    Jour 2 à 3 (jusqu'à une semaine pour un site neuf)Premières données.
    Jour 28Premier vrai rapport, avec lire.
    Puis tous les 28 joursComparaison avec la période d'avant, avec suivre.

    Pourquoi l'utiliser

    • Vous voyez ce qui se passe vraiment. /pulse:seo dit ce qui pourrait freiner le site ; Search Console dit combien de gens l'ont vu et sur quels mots.
    • Chaque chiffre est expliqué. Il est suivi de son sens, puis d'une action ou de « rien à faire, c'est normal ».
    • Vous savez quoi améliorer. Trois actions prioritaires par rapport, vérifiées dans le code de votre site.
    • Aucun secret à donner. Par défaut, vous exportez un fichier depuis Search Console et Pulse le lit.

    Quand l'utiliser

    Conseil : si vous prévoyez de changer bientôt de nom de domaine, attendez ce changement pour relier le site. Vous éviterez de tout recommencer.

    Comment la lancer

    /pulse:search-console [relier | lire [28j|3m] | suivre | inspecter <adresse>]

    Entre crochets [ ] : facultatif. Entre chevrons < > : à remplacer par votre valeur. La barre | sépare les choix possibles. Détecté si vide.

    • relier : une étape à la fois. Ajouter le site dans Search Console, prouver qu'il est à vous (par un code à placer dans la page d'accueil, ou dans les réglages de votre nom de domaine), déclarer le plan du site, l'importer dans Bing, puis choisir comment Pulse lira les données.
    • lire, avec 28j (les 28 derniers jours) ou 3m (3 mois) : le rapport, ses chiffres expliqués et les trois actions prioritaires.
    • suivre : les 28 derniers jours comparés aux 28 jours d'avant, reliés aux changements du site.
    • inspecter suivi de l'adresse complète d'une page : ce que Google sait de cette page, et quoi faire.
    • Rien : Pulse choisit pour vous. Pas encore relié, il propose relier ; pas de rapport, lire ; dernier rapport de 28 jours ou plus, suivre.
    /pulse:search-console relier
    /pulse:search-console lire 3m
    /pulse:search-console inspecter https://carnet-salon.fr/reserver

    Ce qu'elle produit

    FichierÀ quoi il sert

    Pour la vérification par la page d'accueil, Pulse place aussi le code de Google dans le code de votre site. Ce code est public, et il doit rester en place pour toujours.

    Risques et précautions

    • Vous gardez la main chez Google. Ajouter le site, cliquer « Vérifier », déclarer le plan du site et importer dans Bing se font dans l'interface, avec votre compte.
    • La connexion Google est facultative et en lecture seule. Pulse demande seulement le chemin du fichier téléchargé, jamais son contenu. L'accès est rangé hors du projet, dans votre dossier personnel.
    • Retirer l'accès plus tard supprime un fichier : Claude Code vous demande alors l'autorisation.
    • Les mots tapés par les internautes peuvent contenir des noms de personnes. Si votre dépôt est public, Pulse propose de garder le dossier des chiffres bruts hors de Git.

    Attention : ne retirez jamais le code de vérification de Google de votre site. S'il disparaît, Google considère que le site n'est plus à vous, et la propriété se perd après un délai.

    Problèmes et solutions

    « Vérifier » échoue après avoir ajouté l'enregistrement de mon nom de domaine

    La prise en compte peut prendre jusqu'à 24 heures. Pulse note l'étape en cours ; revenez plus tard avec /pulse:search-console relier, et les étapes déjà faites seront sautées.

    « Pas encore de données »

    C'est normal pour un site neuf : les premières données arrivent en 2 à 3 jours, parfois une semaine. Pulse vous donne la date à laquelle revenir.

    Les chiffres sont tout petits et Pulse ne conclut rien

    Avant environ 28 jours et quelques centaines d'apparitions dans Google, les chiffres ne permettent aucune conclusion. Pulse vous le dit plutôt que de commenter du bruit.

    La somme des requêtes est bien plus petite que le total

    Google masque les recherches rares, pour protéger la vie privée. Sur un petit site, l'écart peut dépasser la moitié. C'est normal.

    « Connexion expirée ou retirée »

    Reconnectez-vous en suivant les étapes de relier. Si votre application Google est restée en mode test, publiez-la : sinon, Google coupe l'accès au bout de 7 jours.

    Exemples

    /pulse:search-console relier

    Search Console, c'est le tableau de bord que Google vous tend : ce qu'il a trouvé sur votre site, et ce que les gens ont tapé pour vous trouver. Votre site est sur votre propre domaine, carnet-salon.fr : on le vérifie par un enregistrement dans les réglages du domaine. Ouvrez Search Console avec votre compte Google, choisissez « Ajouter une propriété », puis « Domaine ». Copiez ici la valeur qu'il vous montre (elle n'est pas secrète).

    google-site-verification=Ab12Cd34…

    Ajoutez cette valeur chez votre registraire, je vous guide pas à pas. Puis cliquez « Vérifier ».

    pulse-aidd sonder https://carnet-salon.fr/sitemap.xml --texte "<urlset"

    Le plan du site est bien servi. Déclarez-le dans Search Console : Sitemaps, adresse, Envoyer. Premières données dans 2 à 3 jours ; premier vrai rapport dans 28 jours, avec /pulse:search-console lire.

    /pulse:search-console lire

    Exportez les résultats de recherche des 28 derniers jours (Performances, Exporter), puis donnez-moi le chemin de l'archive téléchargée.

    C:\Users\moi\Downloads\carnet-salon.fr-Performance.zip

    pulse-aidd search-console lire --fichier "C:\Users\moi\Downloads\carnet-salon.fr-Performance.zip" --ecrire

    En bref : votre site est apparu 640 fois dans Google et a reçu 31 visites. Action 1 : « coiffeur sans rendez-vous lyon » vous place en 12e position. Votre page d'accueil en parle peu : enrichissez-la et ajoutez un lien vers elle.
