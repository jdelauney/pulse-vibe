Installer et mettre à jour

Pulse en trois commandes

Une fois Claude Code installé (voir les prérequis), tapez ces commandes dans Claude Code, une à la fois.

Installer

/plugin marketplace add jdelauney/pulse-vibe
/plugin install pulse@pulseia

Pour construire avec la pile Next.js prête à l'emploi (celle des tutoriels), ajoutez le pack. Il installe aussi Pulse :

/plugin install pulse-next@pulseia

Fermez puis relancez Claude Code : les commandes /pulse:… apparaissent.

Mettre à jour

Au début de chaque semaine de travail, dans un terminal :

claude plugin marketplace update pulseia
claude plugin update pulse@pulseia
claude plugin update pulse-next@pulseia

La dernière ligne sert seulement avec le pack Next.js. Fermez puis relancez Claude Code : la nouvelle version se charge au démarrage.

Conseil : pour ne plus y penser, tapez /plugin dans Claude Code, ouvrez Marketplaces, choisissez pulseia, puis Enable auto-update. Le détail, écran par écran, est dans les prérequis.
