Avant de commencer

Prérequis

Tout ce qu'il faut installer et les comptes à créer avant votre premier projet avec Pulse. Vous n'avez jamais installé de logiciel de développeur ? Cette page est faite pour vous : chaque étape est détaillée clic par clic et se termine par une vérification simple.

1 Ce dont vous aurez besoin

Pulse fonctionne à l'intérieur de Claude Code, l'assistant de programmation d'Anthropic. Il lui faut quelques logiciels sur votre ordinateur et, pour mettre votre appli en ligne, quelques comptes sur des sites web. Vous n'aurez rien à programmer : vous allez télécharger, cliquer sur « Suivant », et copier quelques commandes que cette page vous donne.

Où travaillerez-vous avec Pulse ?

Claude Code s'utilise de trois façons. Elles partagent les mêmes réglages : les plugins Pulse, installés une fois, servent partout.

FaçonÀ quoi elle ressemblePour qui
VS Code avec l'extension Claude Code
La façon conseillée		Un éditeur qui montre les fichiers de votre projet, avec un panneau de discussion avec Claude sur le côté.Vous voyez vos fichiers, vous discutez avec Claude dans un panneau, et vous n'avez pas besoin du terminal au quotidien. C'est la façon suivie sur cette page (étapes 2 à 7).
Claude Desktop, onglet CodeUne application avec des boutons, des panneaux et un aperçu des changements.Si vous préférez une application à part (étape 9, facultative).
Claude Code dans un terminalUne fenêtre de texte : vous tapez, Claude répond.Pour les personnes à l'aise avec le texte seul. Les tutoriels de ce wiki montrent les commandes sous cette forme ; elles se tapent de la même façon dans le panneau de VS Code.

Combien de temps ?

Comptez environ une heure et demie pour les logiciels et les plugins Pulse (étapes 2 à 10), puis une demi-heure pour les comptes Neon et Vercel (étapes 11 et 12). C'est une estimation : elle dépend surtout de la vitesse de votre connexion. Vous pouvez vous arrêter entre deux étapes et reprendre plus tard.

Ce qui est gratuit, ce qui est payant

  • Gratuits : VS Code et l'extension Claude Code, Git, Node.js, l'outil GitHub (gh), l'application Claude Desktop, Pulse lui-même, un compte GitHub.
  • Payant : Claude Code demande un abonnement Claude payant (Pro, Max, Team ou Enterprise) ou un compte Console. L'offre gratuite de Claude ne comprend pas Claude Code. Les tarifs à jour sont sur claude.com/pricing.
  • Gratuits pour commencer : Neon (base de données) et Vercel (hébergement) ont une offre gratuite. Attention : celle de Vercel est réservée à un usage personnel et non commercial (détails à l'étape 12).

Votre ordinateur doit avoir au moins Windows 10 (version 1809) ou macOS 13, 4 Go de mémoire et une connexion à Internet.

Cochez au fur et à mesure :

  • VS Code est installé et s'ouvre (étape 2).
  • J'ouvre le terminal de VS Code et j'y colle une commande (étape 3).
  • git --version affiche un numéro de version (étape 4).
  • node --version affiche v22.19 ou plus (étape 5).
  • J'ai un abonnement Claude, l'extension Claude Code est installée et je suis connecté (étape 6).
  • claude --version répond dans le terminal (étape 7).
  • J'ai un compte GitHub, et gh auth status dit que je suis connecté (étape 8).
  • Les plugins Pulse sont installés : /pulse: affiche la liste des commandes (étape 10).
  • J'ai un compte Neon avec un projet en Europe (étape 11).
  • J'ai un compte Vercel relié à GitHub (étape 12).
  • /pulse:init m'accueille dans un dossier d'essai (étape 14).

2 Installer VS Code 10 min

VS Code (Visual Studio Code) est un éditeur gratuit de Microsoft : il affiche les fichiers de votre projet, et c'est là que vous discuterez avec Claude. Vous l'installez en premier : toutes les vérifications de cette page se feront dans sa fenêtre.

Windows

  1. Ouvrez code.visualstudio.com/download et cliquez sur le grand bouton Windows (Windows 10 ou 11).
  2. Ouvrez le fichier téléchargé (VSCodeUserSetup-x64-….exe, dans le dossier Téléchargements). Puis, dans l'installateur :
    • licence : cochez J'accepte l'accord, puis Suivant ;
    • dossier d'installation et dossier du menu Démarrer : gardez tout, Suivant ;
    • Tâches supplémentaires : gardez cochée Ajouter à PATH (elle permet aux autres logiciels de trouver VS Code). Vous pouvez aussi cocher les deux cases « Ajouter l'action « Ouvrir avec Code » » : un clic droit sur un dossier l'ouvrira dans VS Code ;
    • Installer, puis Terminer.

Où le retrouver ensuite : menu Démarrer, « Visual Studio Code ».

macOS

  1. Ouvrez code.visualstudio.com/download et cliquez sur le grand bouton Mac (version « Universal », pour tous les Mac).
  2. Ouvrez le fichier téléchargé, puis glissez Visual Studio Code dans le dossier Applications.
  3. Ouvrez-le depuis Applications. À la première ouverture, macOS demande confirmation : cliquez sur Ouvrir.

Où le retrouver ensuite : dossier Applications, « Visual Studio Code ». Pour le garder dans le Dock : clic droit sur son icône → Options → Garder dans le Dock.

Les menus de VS Code sont en anglais au départ. Ce n'est pas gênant : cette page donne le nom anglais de chaque menu.

Résultat attendu : VS Code s'ouvre sur une page d'accueil (« Welcome »).

Sous Windows, une fenêtre bleue « Windows a protégé votre ordinateur » s'affiche

Vérifiez que le fichier vient bien de code.visualstudio.com, puis cliquez sur Informations complémentaires et Exécuter quand même.

Je préfère VS Code en français

Ouvrez la liste des extensions (Ctrl + Maj + X, ou Cmd + Maj + X sur Mac), cherchez « French Language Pack » publié par Microsoft, installez-le, puis redémarrez VS Code. Les menus seront alors en français.

3 Ouvrir le terminal de VS Code 5 min

Un terminal est une zone où l'on tape des commandes au lieu de cliquer. Vous en aurez besoin pendant l'installation, pour vérifier chaque logiciel. VS Code en contient un : le terminal intégré, qui s'ouvre en bas de sa fenêtre. Rassurez-vous : vous n'aurez qu'à copier et coller les commandes de cette page.

  1. Dans VS Code, ouvrez le menu View (Affichage), puis Terminal. Autre chemin : menu Terminal → New Terminal (Nouveau terminal). Raccourci : Ctrl + ` (la touche de l'accent grave).
  2. Une zone s'ouvre en bas de la fenêtre, avec un curseur qui clignote. Sous Windows, la ligne commence en général par PS C:\Users\VotreNom> : c'est PowerShell, le terminal de Windows.

Coller une commande : copiez-la sur cette page (bouton Copier à droite du bloc), cliquez dans le terminal, puis Ctrl + V (Windows) ou Cmd + V (Mac). Appuyez ensuite sur Entrée.

Pour essayer, collez cette commande, puis Entrée :

echo Bonjour

Résultat attendu : le terminal affiche Bonjour sur la ligne suivante.

Attention : après chaque installation des étapes suivantes, fermez complètement VS Code et rouvrez-le. Un logiciel installé pendant que VS Code est ouvert n'est souvent visible qu'après son redémarrage : fermer seulement le terminal ne suffit pas.

Le terminal de votre système marche aussi, si vous préférez : sous Windows, touches Windows + X puis Terminal ; sous macOS, Cmd + Espace, tapez Terminal, puis Entrée.

Sous Windows, la ligne commence par C:\ sans PS

C'est l'invite de commandes (CMD), l'ancien terminal de Windows. Les commandes de cette page sont écrites pour PowerShell. Dans le terminal de VS Code, cliquez sur la petite flèche à côté du +, en haut à droite du terminal, et choisissez PowerShell.

Je ne peux pas cliquer dans le texte du terminal

C'est normal : on y écrit, on ne clique pas. Déplacez-vous avec les flèches du clavier, et effacez avec la touche Retour arrière.

Une commande semble bloquée

Certaines installations n'affichent rien pendant plusieurs minutes : patientez. Si rien ne bouge après dix minutes, appuyez sur Ctrl + C pour l'arrêter, puis relancez-la.

4 Installer Git 10 min

Git garde l'historique de toutes les versions de votre projet : vous pouvez revenir en arrière à tout moment. Pulse s'en sert à chaque étape.

Windows

Sous Windows, Git for Windows est indispensable : il apporte Git Bash, dont les outils de Pulse ont besoin, et un gestionnaire de connexion à GitHub.

  1. Ouvrez git-scm.com/install/windows.
  2. Dans la partie de l'installateur classique (« Standalone Installer »), cliquez sur la version x64 (fichier Git-2.56.0.2-64-bit.exe le 10 octobre 2026 ; le numéro change avec les mises à jour). Prenez la version ARM64 seulement si votre ordinateur a un processeur ARM, ce qui est rare.
  3. Ouvrez le fichier téléchargé. Windows demande « Voulez-vous autoriser cette application à apporter des modifications ? » : cliquez sur Oui.
  4. L'installateur, en anglais, enchaîne une quinzaine d'écrans. Gardez partout le choix déjà sélectionné et cliquez sur Next. Les écrans à connaître :
    • Information (la licence) : Next.
    • Choosing the default editor used by Git : gardez le choix proposé, Next. Vous n'aurez pas à vous en servir.
    • Adjusting your PATH environment : gardez l'option marquée (Recommended). C'est elle qui permet aux autres logiciels de trouver Git.
    • Choose a credential helper : gardez Git Credential Manager. C'est lui qui ouvrira la connexion à GitHub le moment venu.
  5. Au dernier écran, cliquez sur Install, attendez la fin, puis Finish.

Autre méthode, si vous êtes à l'aise : dans le terminal, cette commande fait la même installation.

winget install --id Git.Git -e --source winget

Où le retrouver ensuite : vous n'avez pas à l'ouvrir. Il apparaît dans le menu Démarrer sous le nom « Git Bash », mais Claude Code s'en sert tout seul.

macOS

Apple fournit Git avec ses « outils en ligne de commande ».

  1. Dans le terminal, collez cette commande, puis Entrée : 
    xcode-select --install
  2. Une fenêtre s'ouvre et propose d'installer les outils : cliquez sur Installer, puis Accepter la licence.
  3. Le téléchargement prend de quelques minutes à une demi-heure. Cliquez sur Terminé à la fin.

Si le terminal répond que les outils sont déjà installés, Git est déjà là : passez à la vérification.

Source : git-scm.com/install/mac, qui propose aussi Homebrew (voir l'étape 8).

Fermez complètement VS Code, rouvrez-le, ouvrez le terminal (View → Terminal), puis vérifiez :

git --version

Résultat attendu : une ligne qui commence par git version, suivie d'un numéro, par exemple git version 2.56.0.windows.2 sous Windows. Le numéro exact importe peu.

« git n'est pas reconnu » ou « command not found: git »

VS Code était ouvert pendant l'installation. Fermez-le complètement, rouvrez-le et réessayez. Si le message reste, relancez l'installation en gardant l'option « Recommended » à l'écran « Adjusting your PATH environment ».

J'ai déjà Git, faut-il le réinstaller ?

Non : si git --version répond, passez à l'étape suivante. Dans le doute, réinstaller ne pose aucun problème.

5 Installer Node.js 10 min

Node.js fait tourner les garde-fous de Pulse (protection de vos clés secrètes, blocage des commandes risquées) et ses outils de vérification. Il installe aussi npm, qui télécharge les briques de votre appli.

Pulse demande Node.js 22.19 ou plus. Prenez la version marquée LTS (« support à long terme », la plus stable) : le 10 octobre 2026, c'est la version 24.21.0.

Windows

  1. Ouvrez nodejs.org/fr/download.
  2. En haut, vérifiez que la version choisie porte la mention LTS (par exemple « v24.21.0 LTS »).
  3. Plus bas, cliquez sur le bouton Windows Installateur (.msi).
  4. Ouvrez le fichier téléchargé (node-v24.21.0-x64.msi, par exemple). Puis, dans l'installateur :
    • premier écran : Next ;
    • licence : cochez la case d'acceptation, puis Next ;
    • dossier d'installation et liste des éléments : gardez tout, Next ;
    • écran des outils pour les modules natifs (« Tools for Native Modules ») : laissez la case décochée, puis Next. Ces outils ne servent pas à Pulse et allongent beaucoup l'installation ;
    • Install, puis Oui quand Windows demande l'autorisation, et enfin Finish.

macOS

  1. Ouvrez nodejs.org/fr/download.
  2. En haut, vérifiez que la version choisie porte la mention LTS (par exemple « v24.21.0 LTS »).
  3. Plus bas, cliquez sur le bouton macOS Installateur (.pkg).
  4. Ouvrez le fichier téléchargé, puis cliquez sur Continuer à chaque écran, Accepter la licence, et Installer. Le Mac demande votre mot de passe de session : saisissez-le. Terminez par Fermer.

Où le retrouver ensuite : nulle part, et c'est normal. Node.js n'a pas de fenêtre : il travaille en coulisse pour Pulse.

Fermez complètement VS Code, rouvrez-le, ouvrez le terminal, puis vérifiez :

node --version
npm --version

Résultat attendu : v24.21.0 (ou tout numéro supérieur à v22.19) pour Node.js, puis un numéro de version pour npm.

Sous Windows, npm --version affiche « l'exécution de scripts est désactivée sur ce système »

Par défaut, Windows interdit à PowerShell de lancer les petits programmes écrits pour lui, dont celui qui lance npm. Autorisez ceux de votre ordinateur, pour votre compte seulement, avec cette commande (réglage décrit par Microsoft sur learn.microsoft.com) :

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Si PowerShell demande une confirmation, acceptez, puis relancez npm --version.

La version affichée est plus ancienne que 22.19

Une ancienne version de Node.js est déjà installée. Installez la version LTS par-dessus depuis nodejs.org, puis fermez et rouvrez VS Code.

Plus tard, Pulse dit « Node.js est introuvable » alors qu'il est installé

Claude Code lit la liste des logiciels au moment où il démarre. Fermez complètement VS Code et rouvrez-le (ou Claude Desktop, ou le terminal, selon la façon dont vous travaillez).

6 L'abonnement Claude et l'extension Claude Code 15 min

Claude Code est l'assistant d'Anthropic qui écrit et modifie le code avec vous. L'extension l'ajoute à VS Code, dans un panneau de discussion. Elle contient sa propre copie de Claude Code : rien d'autre à installer pour discuter avec lui.

Prendre un abonnement

Claude Code demande un compte Claude Pro, Max, Team ou Enterprise, ou un compte Console (paiement à l'usage). L'offre gratuite ne suffit pas. Pour débuter seul, l'abonnement Pro est le plus simple.

  1. Ouvrez claude.com/pricing.
  2. Choisissez une offre et cliquez sur son bouton. Créez votre compte (ou connectez-vous), puis réglez l'abonnement.
  3. Notez l'adresse e-mail utilisée : c'est avec elle que vous vous connecterez dans VS Code.

Installer l'extension

  1. Dans VS Code, appuyez sur Ctrl + Maj + X (Windows) ou Cmd + Maj + X (macOS) : la liste des extensions s'ouvre à gauche. Vous pouvez aussi cliquer sur l'icône des quatre carrés, dans la barre verticale tout à gauche.
  2. Dans le champ de recherche, tapez Claude Code.
  3. Choisissez celle éditée par Anthropic, puis cliquez sur Install. Page officielle : l'extension sur le site de Microsoft.

Ouvrir un dossier

Claude travaille sur les fichiers d'un dossier : le dossier de votre projet. Pour l'instant, créez un dossier d'essai.

  1. Dans votre dossier personnel (ou dans Documents), créez un dossier vide nommé essai-pulse, comme vous créez d'habitude un dossier.
  2. Dans VS Code, menu File (Fichier) → Open Folder… (Ouvrir le dossier), choisissez essai-pulse, puis validez.
  3. VS Code peut vous demander si vous faites confiance aux auteurs des fichiers de ce dossier, ou afficher un bandeau « Restricted Mode » : c'est votre dossier, faites-lui confiance.

Ouvrir le panneau Claude Code et se connecter

  1. Cliquez sur l'icône en forme d'étincelle dans la barre verticale de gauche, ou sur ✻ Claude Code en bas à droite de la fenêtre.
  2. La première fois, un écran de connexion apparaît : cliquez sur Sign in, connectez-vous dans votre navigateur avec le compte de votre abonnement, et acceptez.
  3. Revenez dans VS Code : le panneau Claude affiche une zone de saisie. Une liste « Learn Claude Code » peut apparaître : suivez-la ou fermez-la avec la croix.

Taper une commande

Dans la zone de saisie du panneau, tapez / : la liste des commandes disponibles s'ouvre. C'est ainsi que vous lancerez les commandes de Pulse, comme /pulse:init, une fois les plugins installés (étape 10). Pour envoyer un message, tapez-le puis Entrée.

Résultat attendu : en tapant /, une liste de commandes s'affiche au-dessus de la zone de saisie.

Source : utiliser Claude Code dans VS Code.

L'extension refuse de s'installer

Elle demande VS Code 1.94 ou plus récent. Mettez VS Code à jour : menu Help (Aide), ou Code sur Mac, puis Check for Updates (rechercher les mises à jour).

L'icône en forme d'étincelle n'apparaît pas

Redémarrez VS Code. Ou ouvrez la palette de commandes (Ctrl + Maj + P, ou Cmd + Maj + P sur Mac), tapez Developer: Reload Window et validez.

Le panneau me propose de passer à une offre payante

Le compte utilisé n'a pas d'abonnement compatible. Vérifiez l'adresse e-mail avec laquelle vous vous êtes connecté.

7 Installer Claude Code pour le terminal 10 min

La copie de Claude Code fournie avec l'extension sert à son panneau seulement : elle n'ajoute pas la commande claude au terminal. Or les commandes officielles de mise à jour de Pulse (étape 10) se tapent dans le terminal. Installez donc aussi Claude Code pour le terminal : une seule fois, puis il se met à jour tout seul.

Dans le terminal de VS Code (View → Terminal) :

Windows

La ligne doit commencer par PS (PowerShell). Collez cette commande, puis Entrée :

irm https://claude.ai/install.ps1 | iex

macOS

Collez cette commande, puis Entrée :

curl -fsSL https://claude.ai/install.sh | bash

Rien ne s'affiche pendant le téléchargement : patientez. À la fin, le message Claude Code successfully installed! apparaît. Sources : la documentation officielle de Claude Code et son guide du terminal pour débuter.

Fermez complètement VS Code, rouvrez-le, ouvrez le terminal, puis vérifiez :

claude --version

Résultat attendu : un numéro de version suivi de (Claude Code), par exemple 2.1.211 (Claude Code).

La première fois que vous taperez claude seul dans un terminal, il vous proposera de vous connecter avec votre navigateur, comme l'extension. Pour quitter Claude Code dans le terminal, tapez exit.

« claude n'est pas reconnu » ou « command not found: claude »

Fermez complètement VS Code et rouvrez-le. Si le message reste, le dossier de Claude Code n'est pas encore connu du terminal. Sous macOS, l'installateur affiche la commande qui corrige cela sous « Setup notes », à la fin de l'installation : copiez-la et lancez-la. Sous Windows comme sous macOS, la marche à suivre exacte est dans le guide du terminal, partie « Dépannage ».

Sous Windows : « irm n'est pas reconnu »

Le terminal est l'invite de commandes (CMD), pas PowerShell. Ouvrez un terminal PowerShell (étape 3), puis relancez la commande.

Sous Windows : « Claude Code does not support 32-bit Windows »

Vous avez ouvert « Windows PowerShell (x86) ». Utilisez le terminal de VS Code, ou l'entrée « Windows PowerShell » du menu Démarrer sans « (x86) » dans son nom.

8 GitHub : le compte, l'outil gh et les liens avec Git et VS Code 20 min

GitHub garde une copie de votre projet en ligne, à l'abri d'une panne de votre ordinateur. L'hébergeur Vercel la lit pour mettre votre appli en ligne. Pulse crée toujours votre dépôt (la copie en ligne) en privé : vous seul le voyez.

Créer le compte

  1. Ouvrez github.com/signup.
  2. Saisissez votre adresse e-mail, un mot de passe et un nom d'utilisateur (il apparaîtra dans l'adresse de vos dépôts). Vous pouvez aussi utiliser « Continue with Google ».
  3. Confirmez votre adresse avec le code reçu par e-mail : sans cette confirmation, vous ne pourrez pas créer de dépôt.
  4. Gardez l'offre gratuite : elle suffit.

Conseil : GitHub recommande fortement la validation en deux étapes (un code en plus du mot de passe). Activez-la dans les réglages de votre compte : votre code et vos mises en ligne en dépendent. Guide officiel : créer un compte sur GitHub.

Installer l'outil GitHub (gh)

L'outil gh relie votre ordinateur à votre compte GitHub. Avec lui, Pulse crée votre dépôt privé et y envoie vos versions sans que vous ouvriez le site. Sans lui, Pulse vous guide sur le site de GitHub, étape par étape : c'est plus long.

Windows

Dans le terminal de VS Code, collez cette commande, puis Entrée. Acceptez si Windows demande l'autorisation.

winget install --id GitHub.cli --source winget

Si winget n'est pas reconnu : sur cli.github.com, téléchargez l'installateur pour Windows, ouvrez-le et gardez les choix proposés.

macOS

Sur Mac, la méthode officielle passe par Homebrew, un installateur de logiciels gratuit.

  1. Si vous n'avez pas encore Homebrew, collez cette commande (tirée de brew.sh) dans le terminal, puis Entrée. Elle explique ce qu'elle va faire, demande votre mot de passe de session (rien ne s'affiche quand vous le tapez : c'est normal), puis attend votre accord avec Entrée. 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    À la fin, Homebrew affiche une partie « Next steps » avec des commandes à copier : lancez-les, elles permettent au terminal de trouver Homebrew.
  2. Puis installez gh : 
    brew install gh

Fermez complètement VS Code, rouvrez-le, puis vérifiez dans le terminal :

gh --version

Résultat attendu : une ligne qui commence par gh version, suivie d'un numéro (2.102.0 le 10 octobre 2026).

Relier Git à votre compte

1. Votre nom et votre e-mail. Chaque version enregistrée porte le nom et l'e-mail de son auteur. Réglez-les une fois pour toutes sur cet ordinateur, en remplaçant les exemples par vos informations :

git config --global user.name "Camille Martin"
git config --global user.email "camille@exemple.fr"

Quel e-mail choisir ? Celui de votre compte GitHub. Si votre projet sera visible par d'autres et que vous préférez garder votre adresse privée, GitHub fournit une adresse de remplacement : sur github.com, cliquez sur votre photo de profil, puis Settings → Emails, cochez Keep my email addresses private, et utilisez l'adresse affichée, qui se termine par @users.noreply.github.com. Source : régler l'e-mail de vos versions.

Si vous sautez ce réglage, /pulse:init vous demandera ces deux informations la première fois.

2. La connexion à GitHub. Lancez :

gh auth login

L'outil pose quelques questions en anglais. Choisissez avec les flèches, validez avec Entrée :

  1. Où utilisez-vous GitHub ? Choisissez GitHub.com.
  2. Le protocole préféré pour Git (« preferred protocol for Git operations ») : choisissez HTTPS.
  3. Connecter Git avec vos identifiants GitHub (« Authenticate Git with your GitHub credentials ») : répondez Yes. C'est ce qui permettra à Git d'envoyer vos versions sans redemander de mot de passe.
  4. La façon de vous connecter : choisissez Login with a web browser (se connecter avec le navigateur).
  5. L'outil affiche un code à usage unique de 8 caractères (par exemple ABCD-1234) : notez-le, puis appuyez sur Entrée. Votre navigateur s'ouvre sur GitHub.
  6. Dans le navigateur, saisissez le code, cliquez sur Continue, puis sur le bouton d'autorisation (Authorize github).
  7. Revenez au terminal : il confirme la connexion.

Vérifiez :

gh auth status

Résultat attendu : sous github.com, une ligne avec une coche, du type ✓ Logged in to github.com account VotreNom, et une ligne qui indique https comme protocole pour Git.

Sources : démarrage rapide de l'outil GitHub et garder ses identifiants GitHub dans Git.

Sans l'outil gh : sous Windows, le gestionnaire de connexion installé avec Git for Windows (Git Credential Manager) ouvre une fenêtre de connexion à GitHub au premier envoi. Acceptez-la et connectez-vous avec votre navigateur : la connexion est ensuite gardée.

Relier VS Code à votre compte

VS Code peut aussi se connecter à GitHub, pour envoyer vos versions et voir votre dépôt depuis l'éditeur. Le plus simple : laissez-le vous le proposer. La première fois que VS Code envoie vos versions vers GitHub, il vous demande de vous connecter ; suivez les étapes dans le navigateur (cliquez sur le bouton d'autorisation), puis revenez dans VS Code. Vous pouvez aussi le faire d'avance avec l'icône des comptes (une silhouette), en bas de la barre de gauche, qui propose de se connecter avec GitHub.

Source : travailler avec GitHub dans VS Code.

VS Code reste bloqué sur « Signing in to github.com… »

Si le navigateur ne vous ramène pas dans VS Code : copiez le code d'autorisation affiché dans le navigateur, cliquez dans VS Code sur « Signing in to github.com… » dans la barre du bas, collez le code et appuyez sur Entrée.

Ce que Pulse fera avec ce lien

Vous n'avez rien d'autre à préparer sur GitHub : ne créez pas de dépôt vous-même. Pendant /pulse:init (ou plus tard, à la mise en ligne avec /pulse:deploy), Pulse vous propose de relier le projet à GitHub. Si gh est connecté, il vous montre la commande qui crée un dépôt privé au nom du projet et y envoie la première version, et vous demande votre accord avant de la lancer. Ensuite, il envoie vos nouvelles versions sur GitHub au fil du travail, toujours avec votre accord.

« gh n'est pas reconnu » ou « command not found: gh »

10 Installer les plugins Pulse et les tenir à jour 10 min

Pulse se présente sous forme de plugins (des modules qui s'ajoutent à Claude Code), rangés dans un catalogue nommé pulseia. On ajoute d'abord le catalogue, puis les plugins :

  • pulse : la méthode Pulse, du brief à la mise en ligne. Ses commandes commencent par /pulse:.
  • pulse-next : le pack pour construire une appli web avec Next.js (celle des tutoriels). Il installe aussi pulse.

Installer, dans VS Code

L'extension a un gestionnaire de plugins, avec deux onglets : Plugins et Marketplaces (les catalogues).

  1. Dans le panneau Claude Code, tapez /plugins, puis Entrée : la fenêtre Manage plugins s'ouvre.
  2. Cliquez sur l'onglet Marketplaces. Dans le champ prévu pour ajouter un catalogue, saisissez jdelauney/pulse-vibe et validez. Le catalogue pulseia apparaît dans la liste.
  3. Revenez à l'onglet Plugins. Cherchez pulse, puis cliquez sur Install. Choisissez Install for you : Pulse sera disponible dans tous vos projets, et aussi dans le terminal et Claude Desktop.
  4. Pour une appli web avec Next.js, installez aussi pulse-next, de la même façon (même choix « Install for you »).
  5. Si la fenêtre affiche Restart Claude to apply plugin changes, suivez ce conseil. Dans le doute, fermez complètement VS Code et rouvrez-le.

Ou bien : installer depuis le terminal de VS Code

Les mêmes opérations existent sous forme de commandes. Elles demandent Claude Code pour le terminal (étape 7). Ouvrez le terminal (menu Terminal → New Terminal), puis collez :

claude plugin marketplace add jdelauney/pulse-vibe
claude plugin install pulse@pulseia
claude plugin install pulse-next@pulseia

La dernière ligne sert seulement pour le pack Next.js. Ces commandes installent « pour vous ». Les plugins se chargent au prochain démarrage : fermez complètement VS Code et rouvrez-le.

Dans Claude Code lancé dans un terminal (commande claude), on peut aussi taper /plugin marketplace add jdelauney/pulse-vibe, puis /plugin install pulse@pulseia et /plugin install pulse-next@pulseia, et choisir Install for you (user scope) dans le panneau qui s'ouvre.

Vérifier

Dans le panneau Claude Code, tapez /pulse: (sans appuyer sur Entrée). Dans le terminal :

claude plugin list

Résultat attendu : dans le panneau, la liste des commandes de Pulse s'affiche : /pulse:init, /pulse:express, /pulse:brainstorm… Dans le terminal, claude plugin list affiche pulse@pulseia (et pulse-next@pulseia si vous avez installé le pack), chacun avec sa version et son état.

Mettre à jour Pulse

Les corrections de Pulse arrivent chez vous seulement après une mise à jour. Faites-la au début de chaque semaine de travail, et dès qu'un message de Pulse semble dépassé. Dans le terminal de VS Code :

claude plugin marketplace update pulseia
claude plugin update pulse@pulseia
claude plugin update pulse-next@pulseia

La dernière ligne sert seulement si vous avez installé le pack Next.js. Puis fermez complètement VS Code et rouvrez-le (et Claude Desktop, si vous l'utilisez) : la nouvelle version se charge au démarrage.

Ne plus y penser : la mise à jour automatique

Ce réglage se fait dans Claude Code lancé dans un terminal :

  1. Dans le terminal de VS Code, tapez claude, puis Entrée. La première fois, connectez-vous avec votre navigateur.
  2. Tapez /plugin, puis Entrée.
  3. Ouvrez l'onglet Marketplaces (touche Tab pour passer d'un onglet à l'autre).
  4. Choisissez pulseia, puis Enable auto-update.
  5. Quittez avec exit.

La mise à jour automatique est désactivée au départ : Claude Code ne l'active d'office que pour les catalogues d'Anthropic. Une fois activée, Pulse se met à jour en arrière-plan, et un message vous invite à relancer.

Sources : le README du dépôt Pulse, installer et gérer les plugins et Claude Code dans VS Code (partie sur les plugins).

Les commandes /pulse: n'apparaissent pas

Fermez complètement VS Code et rouvrez-le. Si elles manquent toujours, tapez /plugins : Pulse doit figurer en haut de l'onglet Plugins, avec son interrupteur activé. Un plugin qui n'a pas pu se charger affiche la raison sur sa ligne.

Claude Code signale « not cached » après une mise à jour

Pulse s'appelait autrefois pulse-vibe (et le pack pulse-vibe-next). La mise à jour passe aux nouveaux noms toute seule ; si ce message apparaît, réinstallez une fois pulse (et pulse-next si vous aviez le pack) : dans VS Code avec /plugins, ou dans Claude Code avec /plugin install pulse@pulseia. Puis relancez.

L'ajout du catalogue échoue

Vérifiez votre connexion à Internet et l'orthographe exacte : jdelauney/pulse-vibe. Puis recommencez.

11 Neon : la base de données 15 min

Neon garde les données de votre appli : les comptes de vos clients, leurs réservations… Le pack pulse-next s'en sert. Son offre gratuite est permanente et ne demande pas de carte bancaire.

Risque : Neon vous montrera des adresses de connexion qui contiennent un mot de passe. Ne les collez jamais dans la conversation avec Claude. Pulse vous indiquera le fichier où les coller vous-même (le fichier .env de votre projet), un fichier que l'IA a pour consigne de ne pas lire.

Créer le compte

  1. Ouvrez neon.com/signup.
  2. Créez votre compte. Si la connexion avec GitHub est proposée, prenez-la : un mot de passe de moins à retenir. Sinon, utilisez votre e-mail et confirmez-le.

Créer le projet

Un projet Neon par appli. Vous pouvez le créer dès maintenant :

  1. Dans la console Neon, cliquez sur New Project (Neon peut aussi vous le proposer d'emblée, juste après l'inscription).
  2. Project name : le nom de votre appli, par exemple carnet-reservations.
  3. Region : choisissez AWS Europe (Frankfurt). Vos données restent en Europe, près de l'hébergement choisi par Pulse. La région ne pourra plus être changée ensuite.
  4. Laissez le reste tel quel (le service Postgres database est activé, avec la version proposée).
  5. Cliquez sur Create project. Vous arrivez sur la page Overview du projet.

Résultat attendu : votre projet apparaît dans la console Neon, avec une branche nommée production : c'est là que vivront les vraies données de votre appli.

Source : gérer les projets Neon.

Ce que Pulse vous fera faire ensuite

Quand vous choisirez les outils de votre appli avec /pulse:tech (ou /pulse:express), Pulse vous guidera écran par écran pour :

  • créer une seconde branche, nommée dev, pour vos essais : vos tests ne toucheront jamais les vraies données (vous décocherez alors la case qui supprimerait cette branche au bout d'un jour) ;
  • copier ses deux adresses de connexion (bouton Connect) dans votre fichier .env, que vous créerez vous-même ;
  • plus tard, avant la première version en ligne qui lit la base, relier Neon à Vercel depuis la console Neon (menu Integrations) : les adresses de la version en ligne seront alors fournies à Vercel automatiquement.

Pulse fait le reste lui-même : la structure de la base, ses mises à niveau, et une sauvegarde avant chaque changement de structure en ligne.

L'offre gratuite et ses limites

  • Gratuite et permanente, sans carte bancaire. Jusqu'à 100 projets, 1 Go de données par projet, et un temps de calcul limité chaque mois (100 heures de calcul par projet) : largement assez pour démarrer.
  • La base se met en veille après quelques minutes sans visite : la première visite qui suit est un peu plus lente.
  • Le retour en arrière sur les données est possible sur une courte période (quelques heures sur l'offre gratuite).

Détails et tarifs à jour : neon.com/pricing.

Je me suis trompé de région

La région ne se change pas. Le projet est encore vide : supprimez-le (réglages du projet) et créez-en un nouveau en choisissant « AWS Europe (Frankfurt) ».

Je ne trouve pas Frankfurt dans la liste

La liste est classée par fournisseur et par région. Cherchez la ligne qui contient « Europe » et « Frankfurt » (code aws-eu-central-1).

12 Vercel : l'hébergement 10 min

Vercel met votre appli en ligne, à une adresse que vous pouvez partager. Chaque nouvelle version envoyée sur GitHub y est publiée automatiquement.

Attention : l'offre gratuite de Vercel (Hobby) est réservée à un usage personnel et non commercial. Pour un site qui vend ou qui fait connaître une activité, il faut l'offre Pro, payante. Pour un prototype personnel, l'offre gratuite suffit. Comparez sur vercel.com/pricing.

Créer le compte, avec GitHub

  1. Ouvrez vercel.com/signup.
  2. Cliquez sur Continue with GitHub. C'est le choix conseillé : Vercel a besoin d'être relié à GitHub pour publier votre appli, et ce lien devient votre façon de vous connecter. Avec un simple e-mail, Vercel vous enverrait un code à chaque connexion, et il faudrait relier GitHub plus tard de toute façon.
  3. GitHub vous demande d'autoriser Vercel : cliquez sur le bouton d'autorisation (Authorize Vercel).
  4. Si Vercel vous demande le type d'usage, choisissez l'offre Hobby (projets personnels) et donnez un nom.
  5. Vercel vous propose ensuite d'importer un dépôt ou un modèle : pas maintenant. Votre projet n'existe pas encore ; Pulse vous guidera le moment venu. Vous pouvez fermer la page.

Résultat attendu : vous arrivez sur le tableau de bord de Vercel, connecté avec votre compte GitHub.

Source : la gestion des comptes Vercel.

Facultatif : l'outil Vercel dans le terminal

Il permet à Pulse d'envoyer vos clés secrètes chez Vercel sans qu'elles passent par la conversation, et de vérifier ce qui y est enregistré. Pulse vous le proposera à la mise en ligne ; pour l'installer dès maintenant, dans le terminal de VS Code :

npm i -g vercel
vercel login

vercel login vous demande comment vous connecter : choisissez GitHub, puis confirmez dans le navigateur. Vérifiez :

vercel whoami

Résultat attendu : votre nom d'utilisateur Vercel. Source : vercel.com/docs/cli.

Ce que Pulse fera ensuite

  • La première mise en ligne (avec /pulse:deploy, ou dès le premier jour si vous l'acceptez avec /pulse:tech) : Pulse vous guide sur vercel.com pour créer le projet en important votre dépôt GitHub (Add New… → Project). Vercel reconnaît l'appli tout seul ; Pulse a déjà préparé les réglages (fonctions à Francfort, près de la base).
  • Les clés secrètes : Pulse les envoie chez Vercel par l'outil ci-dessus, ou vous indique où les saisir vous-même dans les réglages du projet (Settings → Environment Variables).
  • Chaque version suivante : Vercel lance les tests, met à niveau la base après une sauvegarde, puis publie. Si un test échoue, la version en ligne reste celle d'avant.

L'offre gratuite et ses limites

  • Gratuite, mais réservée à un usage personnel et non commercial.
  • Des quotas mensuels (trafic, temps de calcul, nombre de mises en ligne par jour) : au-delà, la fonction concernée est suspendue jusqu'à la fin de la période.
  • Les journaux d'erreurs sont gardés une heure seulement.

Détails : l'offre Hobby de Vercel.

J'ai créé mon compte Vercel avec un e-mail

Ce n'est pas grave. Reliez GitHub dans vos réglages Vercel : photo de profil → Settings → Authentication. Vercel vous le demandera aussi à la création du premier projet.

GitHub ne me demande pas d'autoriser Vercel

Vous étiez peut-être déjà connecté et l'autorisation a été donnée. Si Vercel ne voit pas vos dépôts plus tard, Pulse vous montrera comment lui donner l'accès au moment de la première mise en ligne.
