# aidd_docs/memory – La mémoire du projet

Ce que l'IA doit savoir à chaque session pour ne pas tout redécouvrir : les choix faits, les mots du métier, les pièges déjà rencontrés.

## Comment elle se charge

- Les fichiers de ce dossier sont chargés **automatiquement à chaque session**, grâce au bloc mémoire de `CLAUDE.md`.
- `internal/` (décisions détaillées) et `external/` (documents externes) sont lus **seulement quand la tâche le demande**.

## L'entretenir

- `/pulse:memory retenir "…"` : noter une leçon, une convention ou une décision.
- `/pulse:memory actualiser` : vérifier que la mémoire correspond encore au projet.
- Un fait, un seul endroit. Court, à jour, sans secret ni donnée personnelle.
